# T-006｜workspace 模組：路徑、受管區塊、front-matter、原子寫入

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| Albert Chiang | S1 | 2 | feature | [E01-core](E01-core.md) |

**前置票**：[T-001](T-001.md)

**實作需求**：`CORE-FR-003`、`CORE-FR-004`、`CORE-FR-005`、`NFR-004`、`NFR-015`

## 背景

「人工稿永不被覆蓋」靠這一層保證；所有模組寫 Markdown 都要經過它。

## 要做的事

- [ ] 工作區定位（`--workspace`、`NEWSROOM_HOME`、往上找）
- [ ] `read_block`／`write_block`：只改標記之間，標記損壞時 `E_MANAGED_BLOCK`
- [ ] front-matter 讀寫：保留未知欄位與本文
- [ ] 原子寫入（暫存檔＋rename）
- [ ] 所有路徑存相對路徑

## 交付物

- `core/workspace.py`、`core/blocks.py`、`core/frontmatter.py`

## 驗收標準

1. Given 受管區塊外有人寫的文字，When 寫入區塊，Then 區塊外逐位元組不變
2. Given 標記不成對的檔案，When 寫入，Then 回報 E_MANAGED_BLOCK 而且檔案未被修改
3. Given front-matter 有自訂欄位，When 程式更新其他欄位，Then 自訂欄位仍在
4. Given 工作區搬到其他路徑，When 執行指令，Then 仍能正常找到所有檔案

## 測試方式

pytest，包含 property-based 測試（hypothesis）驗證區塊外內容不變。

## 不在這張票的範圍

各模組自己的檔案格式。
