## 背景

GPU 是否可用，決定字幕與 3D、AI 影片走 CPU、GPU 還是雲端（PRD Q1）。

## 要做的事

- [ ] 在 PowerShell 執行 `nvidia-smi`，確認 3090 是否在這台機器
- [ ] 若有：設定 WSL CUDA，並在 WSL 內確認可用
- [ ] 開啟 WSL systemd、啟用 Docker、安裝 ffmpeg（不污染系統：依全域規範）
- [ ] 關閉 Windows 自動睡眠，記錄設定方式
- [ ] 寫成 `docs/environment.md`

## 交付物

- `docs/environment.md`：環境現況表與設定步驟
- 結論：GPU 可用／不可用，以及對字幕、3D、AI 影片的影響

## 驗收標準

1. Given 結論文件，When 主管閱讀，Then 能回答 PRD Q1
2. Given 新的 WSL，When 依文件設定，Then systemd、Docker、ffmpeg 都可用
3. Given GPU 不可用，When 文件完成，Then 列出受影響的 Spike（SPK-SUB-3、SPK-REEL-2、SPK-REEL-3）並註明改用 CPU 或雲端
