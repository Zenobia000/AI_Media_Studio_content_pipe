# T-024｜素材盤點與 media.md（含 L5 缺口）

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| Albert Chiang | S2 | 2 | feature | [E03-fetch](E03-fetch.md) |

**前置票**：[T-022](T-022.md)

**實作需求**：`FET-FR-007`、`FET-FR-009`、`IF-005`、`US-022`、`US-023`

## 背景

assets.json 是草稿與製作都會讀的交棒物；人自己放的素材也靠它進產線。

## 要做的事

- [ ] 掃描 media/raw、gen、proc；SHA-256 產生 asset_id
- [ ] ffprobe 讀長度、解析度、fps、音軌
- [ ] 人放的檔案標 origin=self
- [ ] 依格式判斷缺口並寫入 gaps
- [ ] 產生 media.md
- [ ] `skills/gather-assets/SKILL.md`：決定補料層級、遇到缺口時告訴人缺什麼、要不要等

## 交付物

- `fetch/assets.py`、工具 `assets`
- `skills/gather-assets/`（含 evals）

## 驗收標準

1. Given 放入自錄影片與 wav，When 盤點，Then 兩者出現在 assets.json，origin=self，長度正確
2. Given 刪除一個檔案，When 再盤點，Then assets.json 同步更新，資料庫標記 deleted
3. Given reel 格式但沒有任何畫面素材，When 盤點，Then gaps 有一筆並附建議

## 測試方式

pytest（fixture media）。
