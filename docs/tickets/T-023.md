# T-023｜原文擷取與官方原文補充

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| Albert Chiang | S2 | 2 | feature | [E03-fetch](E03-fetch.md) |

**前置票**：[T-012](T-012.md)、[T-022](T-022.md)

**實作需求**：`FET-FR-001`、`FET-FR-002`、`IF-004`、`US-020`

## 背景

依 SPK-FET-1 的結論實作。交棒物 sources/*.md 是周長曉草稿的輸入。

## 要做的事

- [ ] Extractor adapter：依 Spike 結論的順序嘗試
- [ ] 推文、GitHub、arXiv、YouTube 的特殊處理
- [ ] 從媒體報導找出官方來源並一併擷取
- [ ] 失敗時 blocked 並提示人工貼原文

## 交付物

- `fetch/extract.py`、`fetch/extractors/*`

## 驗收標準

1. Given 20 個真實網址，When 擷取，Then ≥ 85% 成功，失敗都有原因
2. Given 一篇引用官方 blog 的新聞，When 擷取，Then topic 多一個官方來源
3. Given 擷取的 sources/*.md，When schema 驗證，Then 全部通過 IF-004
4. Given 全部方法都失敗，When 擷取，Then Job 為 blocked 並在 notes 提示

## 測試方式

pytest（錄製回應）＋一次真實網址的手動測試。

## 不在這張票的範圍

影片與圖片（T-038、T-039）。
