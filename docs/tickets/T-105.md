|---|---|---|---|---|

**前置票**：[T-035](T-035.md)

**實作需求**：`COL-FR-010`、`US-018`

## 背景

沒有 RSS 的 changelog、定價頁也能監測。

## 要做的事

- [ ] Docker 部署 changedetection.io（需要 JS 的頁面才開瀏覽器抓取）
- [ ] webhook 接回 newsroom，建立 source
- [ ] 20 個頁面跑 14 天，統計假警報

## 交付物

- `collect/collectors/changedetect.py`、`docker-compose.yml`
- `docs/spikes/SPK-COL-4.md`

## 驗收標準

1. Given 測試頁面修改，When 15 分鐘內，Then 出現在候選
2. Given 14 天數據，When 統計，Then 假警報 ≤ 1 次／頁／週（未達時調整篩選器）
3. Given changedetection 服務停止，When 收集，Then 其他來源正常

## 測試方式

實測＋pytest。
