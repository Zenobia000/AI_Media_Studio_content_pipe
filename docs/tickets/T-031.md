# T-031｜approve 與 unapprove

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| 楊舒媁 | S2 | 2 | feature | [E08-publish](E08-publish.md) |

**前置票**：[T-030](T-030.md)

**實作需求**：`PUB-FR-003`、`PUB-FR-004`、`AGT-FR-005`

## 背景

確認綁定版本；之後任何輸入變動都要讓確認失效。

## 要做的事

- [ ] approve：檢查 ready、未過期、待確認項已處理；綁定 build 或文字雜湊
- [ ] unapprove 與自動撤銷（由 T-076 呼叫）
- [ ] approvals 資料表的寫入
- [ ] 關卡寫在工具裡（AGT-FR-005）：approve 需要 `--confirmed-by-human` 與人的確認原文；headless 執行（有 `NEWSROOM_HEADLESS`）一律拒絕
- [ ] 發布類工具沒有有效 approval 時回報 E_NOT_APPROVED

## 交付物

- `publish/approve.py`、CLI `approve`、`unapprove`

## 驗收標準

1. Given ready 且待確認項都已處理，When approve，Then Content 進入 approved 並綁定版本
2. Given Threads 確認後修改 caption.md，When status，Then 確認失效、回到 review
3. Given 撤銷後再確認，When 查詢，Then 有兩筆 approval，舊的有 revoked_at
4. Given headless 模式，When agent 嘗試 approve，Then 工具拒絕並記錄
5. Given 互動模式但沒有確認原文，When approve，Then 被拒絕

## 測試方式

pytest。
