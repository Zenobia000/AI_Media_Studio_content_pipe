## 背景

寫稿由 agent 依 skill 完成（ADR-09），程式負責把關：格式、素材、禁用詞。這是周長曉交棒給製作與確認流程的主要產出。

## 要做的事

- [ ] 三個節目模板 `templates/programs/*.md`
- [ ] `draft.json` schema（threads、carousel、reel 的結構化部分）
- [ ] `skills/draft-content/SKILL.md` 的寫稿段：先看素材再寫、facts 以外不寫、只用存在的 asset、讀 voice 與 glossary
- [ ] 工具 `draft-save <content_ref> <dir>`：schema、asset_id 存在、裁切範圍、禁用詞與台灣用語，通過後存成新 revision，meta.json 記 run_id
- [ ] eval 案例：fixture topic 三種格式各一

## 交付物

- `draft/save.py`、工具 `draft-save`、`templates/programs/`
- `skills/draft-content/SKILL.md`（寫稿段）、`evals/draft.yaml`

## 驗收標準

1. Given fixture topic，When 跑 eval，Then 三種格式都通過 draft-save
2. Given 節奏表引用不存在的 asset_id，When draft-save，Then 指出位置並拒絕存檔
3. Given 草稿出現 glossary 禁用詞，When draft-save，Then 存檔成功並列為待確認項
4. Given 新增一個節目模板檔，When 寫稿，Then 不需要改程式或 skill

## 測試方式

pytest（draft-save）；`newsroom eval draft-content`；在 2 則真實題目上手動試用。
