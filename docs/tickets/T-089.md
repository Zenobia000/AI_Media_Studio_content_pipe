**前置票**：[T-088](T-088.md)、[T-076](T-076.md)

**實作需求**：`PUB-FR-013`、`US-073`

## 背景

確認後由系統在指定時間發布；發布前再檢查一次。

## 要做的事

- [ ] 排程器取出到期的 scheduled Publication
- [ ] 發布前再次檢查 approved 且未過期
- [ ] 總開關（預設關）與每日上限
- [ ] 失敗重試（最多 3 次）並通知

## 交付物

- `publish/scheduler.py`

## 驗收標準

1. Given 預定時間前修改稿件，When 到期，Then 發布被擋下並通知
2. Given 總開關關閉，When 到期，Then 不發布只提醒
3. Given 暫時性錯誤，When 發布，Then 指數退避重試最多 3 次

## 測試方式

pytest。
