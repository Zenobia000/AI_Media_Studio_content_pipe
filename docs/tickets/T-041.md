- [ ] 建立 Meta App 與測試用的 IG 專業帳號、Threads 帳號
- [ ] 申請 `threads_keyword_search`、`threads_manage_insights`、`instagram_business_content_publish` 等權限
- [ ] 記錄審核時間與要求
- [ ] 把 token 存到 keyring 的方式寫成文件
