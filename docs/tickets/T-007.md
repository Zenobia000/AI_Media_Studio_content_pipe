**實作需求**：`CORE-FR-006`

## 背景

執行紀錄的主資料。資料表的負責人見 SRS 01 §6。

## 要做的事

- [ ] `migrations/0001_init.sql`：SRS 01 §6 的所有資料表
- [ ] 啟動時自動套用未套用的 migration；WAL；foreign key on
- [ ] 每個資料表一個 repository 模組，寫入只透過負責人的函式
- [ ] `data/fixture.sql` 和 fixtures 對齊

## 交付物

- `core/db.py`、`core/migrations/`
- repository 函式骨架

## 驗收標準

1. Given 空資料庫，When 啟動，Then 所有 migration 套用成功
2. Given 已套用的資料庫，When 再次啟動，Then 不報錯、不重複套用
3. Given 插入不存在的外鍵，When 寫入，Then 被拒絕

## 測試方式

pytest：migration 測試、外鍵測試。

## 不在這張票的範圍

各模組的查詢邏輯。
