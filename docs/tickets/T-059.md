## 背景

研究推估 X API 每月 90–225 美元，比原估高；接 X 之前要實測（PRD Q2）。

## 要做的事

- [ ] 一個 150 人 List，每 15 分鐘輪詢＋since_id，跑 7 天
- [ ] 記錄每日回傳則數與實際帳單
- [ ] 測試 `exclude=replies,retweets` 能否用在 List 端點
- [ ] 測試書籤讀取與 media variants

## 交付物

- `docs/spikes/SPK-COL-1.md`：數據、月費推估、建議人數

## 驗收標準

1. Given 7 天數據，When 推估，Then 有月費估算與信賴區間
2. Given 月費 > 60 美元，When 寫結論，Then 提出縮減方案（核心 50 人＋AINews）
3. Given 結論，When 主管閱讀，Then 能決定 PRD Q2

數據腳本。
