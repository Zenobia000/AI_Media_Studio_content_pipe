**實作需求**：`COL-FR-020`、`COL-FR-021`、`IF-002`、`IF-003`、`US-004`

## 背景

produce 的第一步，也是 Albert 交棒給後續流程的起點。

## 要做的事

- [ ] 工具 `open-topic`：依 candidate_id 找回或建立 topic；依格式建立 content（不重建）；notes.md 寫入備註
- [ ] 候選合併（備註 `合併到 cand_xxx` 與工具 `merge`）
- [ ] `skills/open-topic/SKILL.md`：從 inbox 勾選或口頭指定（「第 3 題」）找到候選，決定節目、格式與角度，再呼叫工具

## 交付物

- `collect/topics.py`、工具 `open-topic`、`merge`
- `skills/open-topic/`（含 evals）

## 驗收標準

1. Given 已勾選的候選，When 執行兩次建題，Then topic 與 content 都只有一份
2. Given 第二次在格式多加 reel，When 建題，Then 只新增 reel-01
3. Given 兩個候選合併，When 建題，Then 只有一個 topic，source_ids 包含兩邊
4. Given 使用者說「第 3 題做 Threads」，When agent 用 open-topic skill，Then 建立正確候選的 threads-01

## 測試方式

pytest。
