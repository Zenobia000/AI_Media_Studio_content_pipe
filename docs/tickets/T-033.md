# T-033｜RESOLVER 口語案例與 R1 skill 路由驗收

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| 周長曉 | S2 | 1 | chore | [E01-core](E01-core.md) |

**前置票**：[T-026](T-026.md)、[T-015](T-015.md)、[T-110](T-110.md)

**實作需求**：`AGT-FR-002`

## 背景

2026-10-24 由「slash commands」改為本票（ADR-09）：人不再背指令，改用口語。這張票確認 agent 聽得懂、會載入正確的 skill。

## 要做的事

- [ ] 收集 15 句創作者真實會說的話（例如「今天有什麼」「第 3 題做成 Reel」「為什麼卡住」）
- [ ] 寫成 RESOLVER 的 eval 案例：每句應載入哪個 skill
- [ ] 依結果調整 `RESOLVER.md` 與各 skill 的 `description`
- [ ] 給創作者的一頁說明：可以怎麼說、哪些事一定要自己確認

## 交付物

- `skills/RESOLVER.md`、`skills/_resolver-evals/*.yaml`
- `docs/runbooks/how-to-talk-to-newsroom.md`

## 驗收標準

1. Given 15 句口語需求，When 跑 eval，Then ≥ 90% 載入正確 skill
2. Given 一句模糊的需求（例如「處理一下這個」），When agent 執行，Then 先反問，不直接呼叫會改狀態的工具
3. Given 創作者照一頁說明操作 R1 流程，When 驗收（T-034），Then 不需要查任何指令

## 測試方式

`newsroom eval --resolver`。

## 不在這張票的範圍

各 skill 的內容（各自的票）。
