# T-030｜review 預覽與待確認項處理

**實作需求**：`PUB-FR-001`、`PUB-FR-002`、`US-070`

## 背景

「看過不等於確認」的第一步：把所有需要人判斷的東西集中在一個地方。

## 要做的事

- [ ] 產生 review.md 與終端機摘要（成品、來源、待確認項、下一步）
- [ ] 待確認項來源：未驗證說法、用語問題、素材用法（R1）；念稿差異與規格（後續票補上）
- [ ] 三種處理方式：改稿重做、在 review.md 打勾寫說明、`--accept`
- [ ] `skills/review-and-approve/SKILL.md`：把預覽與待確認項整理給人看；只有人明確說確認時才呼叫 approve，並附上人的原話

## 交付物

- `publish/review.py`、CLI `review`

## 驗收標準

1. Given 一則有未驗證數字的 Threads，When review，Then 待確認項列出該數字與位置
2. Given 打勾但沒寫說明，When approve，Then 被拒絕並要求說明
3. Given 所有待確認項都處理，When 查看 approvals 明細，Then 有每一項的處理紀錄

## 測試方式

pytest＋CliRunner。

## 不在這張票的範圍

成品預覽圖（隨輪播、Reel 票補上）。
