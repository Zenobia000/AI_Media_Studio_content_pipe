| 負責人 | Sprint | 估點（人天） | 類型 | Epic |

| 楊舒媁 | S3 | 2 | feature | [E09-feedback](E09-feedback.md) |

**前置票**：[T-050](T-050.md)、[T-015](T-015.md)

**實作需求**：`FB-FR-003`、`US-082`

## 背景

每週檢討的依據。

## 要做的事

- [ ] 工具 `retro-data`：彙整 Publication 與最新 snapshot，依節目、格式、平台比較；速度統計；只出數字
- [ ] `skills/weekly-retro/SKILL.md`：讀數字寫週報與 3–5 條建議，標明是建議；數字一律引用工具輸出
- [ ] 輸出 reports/weekly.md；可由 `newsroom run weekly-retro` 排程執行

## 交付物

- `feedback/retro_data.py`、工具 `retro-data`、`skills/weekly-retro/`（含 evals）

## 驗收標準

1. Given 5 則 Publication，When retro，Then 數字與資料庫一致
2. Given 建議段落，When 檢查，Then 有「建議，由人決定」標示
3. Given 本週沒有任何發布，When retro，Then 產出說明而不是報錯

## 測試方式

pytest（FakeLLM）。
