# T-009｜Step 介面與 Job 協調器（指紋、鎖）

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|

**前置票**：[T-007](T-007.md)

**實作需求**：`CORE-FR-010`、`CORE-FR-011`、`IF-014`、`IF-015`、`NFR-003`

## 背景

所有花錢或花時間的工作都包成 Step，由協調器統一處理冪等、鎖、重跑與預算。這是三人模組能接起來的插座。

## 要做的事

- [ ] 定義 `Step` Protocol 與 `StepResult`（IF-015）
- [ ] Job 建立、狀態轉換、結果記錄
- [ ] 指紋：相同指紋而且已成功時不重跑
- [ ] 鎖：SQLite locks 表＋PID＋心跳；失效可接手
- [ ] 提供一個 `EchoStep` 範例與測試，讓其他人照著寫

## 交付物

- `orchestrator/step.py`、`jobs.py`、`locks.py`
- `docs/how-to-write-a-step.md`

## 驗收標準

1. Given 同一個 Step 與相同輸入，When 連續執行兩次，Then `run` 只被呼叫一次
2. Given 兩個程序同時執行同一目標，When 第二個取鎖，Then 得到 E_LOCKED
3. Given 持有鎖的程序被 kill，When 下一次執行，Then 可以取得鎖
4. Given Step 回傳 blocked，When 查詢 Job，Then 狀態是 blocked 且保留原因

## 測試方式

pytest，含多程序並行測試。
