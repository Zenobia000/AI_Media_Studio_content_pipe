## 背景

三段式草稿的第一段。所有數字的依據都從這裡來。

## 要做的事

- [ ] 讀 topic 的 sources/*.md，以 document 形式送進 LLM 並開 citations
- [ ] 輸出 facts.json（SRS 04 DRF-FR-001 格式）
- [ ] 依 sources 雜湊快取
- [ ] 在 fixture topic 上跑通

## 交付物

- `draft/facts.py`
- facts.json schema（加入 `schemas/`）

## 驗收標準

1. Given fixture topic，When 抽取，Then facts.json 通過 schema 且每個 cited_text 都能在原文逐字找到
2. Given sources 沒變，When 再執行，Then 不呼叫 LLM
3. Given topic 沒有任何來源，When 抽取，Then Job 為 blocked（E_MISSING_SOURCE）

## 測試方式

pytest（FakeLLM＋錄製回應）。
