## 背景

原文擷取是草稿品質的源頭；先用真實網址確認 trafilatura 加備援能覆蓋多少。

## 要做的事

- [ ] 蒐集 50 篇真實來源（官方 blog、科技媒體、中文媒體、arXiv、GitHub）
- [ ] 人工標註正文
- [ ] 比較 trafilatura（＋curl_cffi）、Jina Reader、Crawl4AI
- [ ] 量測正文完整率、雜訊比例、日期正確率、耗時

## 交付物

- `docs/spikes/SPK-FET-1.md`：數據、結論、建議的擷取順序

## 驗收標準

1. Given 50 篇樣本，When 跑完比較，Then 文件中有每個方案的四項數據
2. Given 結論，When 套用建議順序，Then 覆蓋率 ≥ 95%（未達時說明缺口與替代方案）
3. Given Jina 免費額度限制，When 寫結論，Then 註明授權與費用影響

## 測試方式

可重跑的比較腳本放在 `spikes/fet1/`。
