# T-025｜引用檢查（程式比對數字與專有名詞）

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| 周長曉 | S2 | 2 | feature | [E04-draft](E04-draft.md) |

**前置票**：[T-017](T-017.md)

**實作需求**：`DRF-FR-004`、`US-031`

## 背景

三段式草稿的第三段。不靠 LLM 自己判斷，用程式保證沒有來源的數字一定被標出來。

## 要做的事

- [ ] 抽出數字（含中文數字、百分比、倍數、金額、日期）與英文專有名詞
- [ ] 正規化（八成＝80%、1.5 億＝150M）
- [ ] 比對 fact 的 cited_text
- [ ] 輸出 citations.json 並在 Markdown 標 ⚠待確認

## 交付物

- `draft/check.py`、測試資料集

## 驗收標準

1. Given 10 份有標準答案的草稿（50 個數字與名詞），When 檢查，Then 漏標 = 0 且誤報 ≤ 10%
2. Given 「八成」對應 fact 中的 80%，When 檢查，Then 判為 verified
3. Given 沒有任何 fact 的數字，When 檢查，Then 標為 unverified 並出現在 Markdown

## 測試方式

pytest 參數化測試。

## 不在這張票的範圍

review 呈現（T-030）。
