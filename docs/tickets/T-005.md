# T-005｜config 載入與日誌（含金鑰遮罩）

| 負責人 | Sprint | 估點（人天） | 類型 | Epic |
|---|---|---|---|---|
| 楊舒媁 | S1 | 1 | feature | [E01-core](E01-core.md) |

**前置票**：[T-001](T-001.md)

**實作需求**：`CORE-FR-007`、`CORE-FR-008`、`NFR-011`

## 背景

每個模組都要讀設定、寫日誌；金鑰不能出現在任何檔案或日誌。

## 要做的事

- [ ] Pydantic 定義 `config.toml` 結構；每個整合都有 `enabled`
- [ ] 金鑰只從環境變數讀取
- [ ] JSONL 日誌（SRS 00 §5.7）
- [ ] 遮罩函式：所有外部呼叫的參數與 header 先經過它

## 交付物

- `core/config.py`、`core/log.py`
- `config.toml` 範本

## 驗收標準

1. Given 某個整合 enabled=false，When 呼叫相關功能，Then 顯示「未啟用」而不是報錯
2. Given 用假金鑰跑完一次流程，When grep 日誌，Then 找不到金鑰字串
3. Given config 欄位型別錯誤，When 載入，Then 錯誤訊息指出欄位與期待的值

## 測試方式

pytest 單元測試；日誌 grep 測試。

Job 層的成本紀錄（T-009、T-078）。
