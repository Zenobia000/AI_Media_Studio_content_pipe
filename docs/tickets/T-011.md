## 背景

R1 的唯一來源。創作者滑手機看到好題目就丟進來。

## 要做的事

- [ ] `newsroom add-source <url> [--note] [--program] [--formats]`
- [ ] 寫入 sources 與 candidates
- [ ] 重複網址時附加備註並告知在哪一天的 inbox

## 交付物

- `collect/collectors/manual.py`、CLI 指令

## 驗收標準

1. Given 新網址，When add-source，Then 資料庫有一筆 source 與一筆 candidate
2. Given 已存在的網址，When 再 add-source 並附備註，Then 不重複建立且備註被保留
3. Given 不合法的網址，When add-source，Then 結束碼 2 並說明原因

## 測試方式

pytest＋CLI 測試（CliRunner）。
