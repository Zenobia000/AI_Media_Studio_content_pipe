## 背景

S4 字幕實作前，用創作者自己的錄音決定工具組合（技術選型 §2.2–2.3）。

## 要做的事

- [ ] 請創作者錄 10 段 30–90 秒、中英夾雜的旁白（附講稿）
- [ ] SUB-1：Breeze-ASR-25、Qwen3-ASR（＋OpenCC）、whisper-large-v3-turbo 的 CER 與術語錯誤
- [ ] SUB-2：人工標 3 段每字起點，比較 Qwen3-ForcedAligner、WhisperX（先轉簡體再對齊）、Breeze word_timestamps
- [ ] SUB-3：CPU（與 GPU）的處理速度
- [ ] SUB-4：30 句比較 CKIP 與 jieba＋glossary，BudouX＋規則分行

## 交付物

- `docs/spikes/SPK-SUB.md`：四項數據與建議組合
- 測試音檔與標註（放在不進版本控制的資料夾，路徑寫進文件）

## 驗收標準

1. Given 10 段錄音，When 比較 ASR，Then 有每個方案的 CER 與術語錯誤數
2. Given 3 段人工標註，When 比較對齊，Then 有平均誤差與 > 200 ms 的比例，並選出 ≤ 80 ms 的方案（都未達時說明替代方案）
3. Given 速度數據，When 寫結論，Then 60 秒錄音的全流程時間與 CPU／GPU 差異都有記錄
4. Given 斷詞比較，When 寫結論，Then 術語被切斷次數與 F1 都有記錄

## 測試方式

可重跑的評測腳本。
