## 背景

人工稿保護的核心規則。

## 要做的事

- [ ] `draft-save` 每次存成新 revision，不寫入 content 資料夾
- [ ] 第一次自動選用 r001
- [ ] 工具 `select`：人改過時先備份成 `-edited`；列入 skill 的 gates（只有人指定時才能呼叫）
- [ ] skill 的改稿段：讀人的修改要求（對話或 notes.md），寫新稿，記在 meta.json 的 `request`

## 交付物

- `draft/versions.py`、工具 `select`
- `skills/draft-content/SKILL.md`（改稿段）

## 驗收標準

1. Given 人修改 script.md，When 要求改稿，Then script.md 不變，新稿在 drafts/r002
2. Given 人改過稿件，When select r002，Then 原稿備份到 drafts/r001-edited
3. Given 補了自錄影片並重新盤點，When 要求改稿，Then 新節奏表使用這段影片
4. Given 沒有人指定版本，When skill 執行，Then 不會呼叫 select

## 測試方式

pytest。
