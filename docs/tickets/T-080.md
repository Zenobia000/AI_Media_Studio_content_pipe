## 要做的事

- [ ] `skills/morning-brief/SKILL.md`：讀 inbox 與 status，整理昨晚以來的 S／A 級候選與建議切角、進行中、被阻擋、今天的發表會、待填回的排程
- [ ] 07:30 以 `newsroom run morning-brief` 產生 reports/morning/YYYY-MM-DD.md
- [ ] 推播摘要

## 交付物

- `skills/morning-brief/`（含 evals）、排程設定

## 驗收標準

1. Given 固定時間觸發，When 產生早報，Then 內容與資料庫一致
2. Given 有被阻擋的工作，When 產生，Then 列出並附下一步指令
3. Given 沒有任何新候選，When 產生，Then 仍產出簡短早報
