**實作需求**：`AGT-FR-008`

## 背景

取代原本寫死的 produce 管線（ADR-09）。這張票把 Albert 的建題、補料與周長曉的草稿串成一個 skill，是 R1 的主幹；順序由 skill 依情況決定。

## 要做的事

- [ ] `skills/produce-topic/SKILL.md`：依序呼叫 open-topic → gather-assets → draft-content；素材已齊就跳過補料；只要求一種格式時只寫一種；缺口時先回報並問人
- [ ] 一題 blocked／failed 時記下原因，繼續處理其他題
- [ ] 結束時輸出每個 topic、content 的結果摘要，附 run_id
- [ ] eval 案例：三題中一題擷取失敗；只出 Threads；素材已齊

## 交付物

- `skills/produce-topic/`（SKILL.md＋evals）

## 驗收標準

1. Given 三題中一題擷取失敗，When produce-topic，Then 另外兩題產出草稿，摘要列出失敗原因
2. Given 草稿步驟失敗後修好，When 再執行，Then 擷取與盤點不重跑（ledger 冪等）
3. Given 同一個 eval 案例跑 3 次，When 檢查，Then 3 次都產出通過 draft-save 的草稿

## 測試方式

`newsroom eval produce-topic`（fixture 工作區）；一則真實題目手動試用。

## 不在這張票的範圍

排程觸發（T-048）；確認與發布的 skill（T-030、T-032）。
