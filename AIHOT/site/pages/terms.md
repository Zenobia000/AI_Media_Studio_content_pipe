頁首說明：

> 本站聚合公開信源，用模型生成中文摘要與精選，原文版權歸各來源所有。網頁、RSS、公開 API 與 MCP 均可匿名使用。

## 1. 內容與版權

本站展示的標題、摘要和推薦理由由模型根據公開來源生成，可能有誤，重要資訊請以原文為準。原文版權歸各來源所有；站內只在來源允許時展示全文，其餘只展示摘要和原文連結。

## 2. 來源方的更正與下架

如果你是來源方，希望更正、下架或調整展示方式，請通過反饋頁聯絡我們，我們會盡快處理。

## 3. 使用本站的資料

請寫明你允許的用途（例如個人閱讀、組織內部使用），以及需要事先取得你同意的用途（例如商業產品、公開轉載、批次再分發）。

## 4. 介面與頻率

RSS、公開 API 和 MCP 為匿名只讀介面。請按響應中的快取時間輪詢，遇到 429 請遵守 Retry-After，不要併發重試。

## 5. 免責

本站按“現狀”提供，不保證內容完整、準確和持續可用。
