# RESOLVER：口語需求 → skill

這是空殼（T-001）。完整格式、關卡與各模組的 skill 由 T-015 定義（負責人：周長曉）。下面只列素材收集已經寫好的 skill，說法照各 skill 的 `description`。

| 創作者的口語需求 | skill | 做什麼 |
|---|---|---|
| 「幫我整理 inbox」「今天有什麼值得做」「標題翻成中文」 | [triage-inbox](triage-inbox/SKILL.md) | 替外文標題補中文標題，說明哪幾題值得先看；不勾選、不建題 |
| 「做第 3 題」「把勾選的建題」「這題出 Threads 和 Reel」「這兩題合成一題」 | [open-topic](open-topic/SKILL.md) | 依 inbox 勾選或口頭指定的候選建立題目與各格式的稿件，或合併候選 |
| 「幫我抓原文」「這題有哪些素材」「缺什麼畫面」「我放了影片，更新一下」「原文抓不到怎麼辦」 | [gather-assets](gather-assets/SKILL.md) | 替已建好的題目補原文與素材，並盤點缺什麼 |

寫新 skill 時：front-matter 的 `tools` 要列出它會呼叫的 `newsroom` 工具（格式見 [triage-inbox](triage-inbox/SKILL.md)），並在這張表加一列。
